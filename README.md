## 这是什么

「筱溪智能助手」是一款 Windows 桌面智能助手程序。本仓库**仅发布编译后的可执行产物**，用于作者权属与完成时间的存证，**不包含任何 Python 源代码**。

- **产物形态**：Windows x64 独立可执行文件（`筱溪智能助手.exe`）
- **下载地址**：见本仓库 [Releases](../../releases) 页（完整 exe 因体积超过 100MB，以 Release 附件形式分发）
- **构建日期**：2026-10-14
- **目标平台**：Windows x64（Python 3.11 运行时已静态打包，无需另行安装）

## 技术栈与保护方式

| 环节 | 说明 |
| --- | --- |
| 核心模块编译 | Python 核心模块经 **Cython** 编译为 C，再编译为原生扩展（`.pyd`，机器码） |
| 独立打包 | 经 **PyInstaller** onefile 模式打包为单一 `exe`，内嵌运行时 |
| 源码保护 | **不发布 `.py` 源码**；核心逻辑以编译后的机器码形式存在，显著提高逆向/篡改门槛 |

> 说明：以编译产物形式发布，是为了在不公开源码的前提下完成权属存证。核心业务逻辑已编译进 C 扩展，普通文本层面不可读取源码。


# ⚠️ 历史版本存档 · th7.1（早期版本，仅供展示）

> **【必读警示】本文件夹是筱溪（XIAOXI）的早期历史版本存档，不是当前版本，也不代表现在的技术水平。**
> 它存在的唯一目的：作为「历史版本证明」公开展示早期代码形态与后续演进的对照。

## 这是什么版本

- **版本标识**：XIAOXI v3.0.0「工业级文学创作版」（内部代号 th7.1）
- **开发期**：2026 年 4 月 ~ 6 月（本存档内文件时间戳约 2026-05-28 / 2026-06-08）
- **开发方式**：**纯手工逐文件编写，全程没有使用任何智能体/Agent 辅助**，一行一行对着改出来的
- **已知状况**：正因为是手工快速堆叠的早期代码，**里面充满 bug、补丁压补丁的债务、重复逻辑和不一致的命名**。这是那个阶段的真实状态，原样（部分修复后）公开，不做美化

## 使用警告

- **请勿用于生产用途**。这是展示/考古/教学参考用的存档
- 架构是 Ollama 时代的旧链路（`call_ollama_safe` / 意图状态机 / 任务计划器），与现在的筱溪完全不是一套体系
- 其中的「工业级」「完美」「绝杀」等夸张注释是早期自嗨式命名习惯，一笑置之即可

## 上传前做过的轻量修复（2026-06 存档整理）

只修了「功能性坏掉」的点和明确的债务，**刻意保留大部分历史面貌**（包括奇怪的命名和巨型文件）：

| 修复 | 说明 |
| --- | --- |
| 意图状态机误拦截 | `planned` 态白名单漏放 `project_creation`，导致创建指令被降级为闲聊 |
| `list_all_tasks` 缺失 | `TaskPlanner` 未定义该方法，调用处 `AttributeError` |
| 写章链路 `self.task_plan` 漏赋值 | `AttributeError` 被外层吞掉，表现为「章节永远不落盘」 |
| 初始状态无兜底 | LLM 初始状态 JSON 失败时 `world_state/character_state` 不落盘，项目永久无法写章；已加兜底骨架（兜底路径日志显式标注） |
| 确认大纲结果被无条件包装 | 批内生成失败被 `outline_confirmed` 掩盖成成功，已保留真实失败状态 |
| 测试 mock 契约修正 | mock 误路由（JSON 期望拿到长文等）、写章分支标记，`tests/test_full_flow_mock.py` 与 `tests/test_fast_flow.py` 端到端全绿 |
| 债务清理 | 删除死代码/失效补丁若干（详见 `misc_scripts/` 保留的历史脚本） |

验证方式（在本目录下）：

```bash
python -m unittest tests.test_full_flow_mock tests.test_fast_flow -v
python -m compileall -q core tests main.py
```

## 目录结构

| 目录/文件 | 说明 |
| --- | --- |
| `core/` | 全部核心源码（约 86 个模块，含 GUI、大纲、章节生成、意图分析等） |
| `tests/` | 测试（mock 全流程、极速全流程连通性等） |
| `main.py` | 入口 |
| `requirements.txt` | 依赖清单 |
| `README_guide.txt` | 当年的使用指南（原文，未改动） |

| `misc_scripts/` | 当年的杂项调试/诊断脚本（历史遗迹，保留原样） |

| 原名 | 现名 |

| `README_使用指南.txt` | `README_guide.txt` |
| `全流程升级！.py` | `misc_scripts/full_flow_upgrade_legacy.py` |
| `测试全流程小说生成全流程版.py` | `misc_scripts/e2e_novel_pipeline_legacy.py` |
